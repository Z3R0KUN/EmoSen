# EmoSen

EmoSen is an emotion and sentiment analysis system that detects human emotions using
deep learning and NLP techniques. The project combines text-based sentiment analysis
and facial emotion recognition using a trained neural network model.

## Features
- Text emotion and sentiment analysis
- Facial emotion detection using a trained CNN model
- Real-time emotion detection support
- Modular and extensible Python codebase

## Tech Stack
- Python
- TensorFlow / Keras
- OpenCV
- NumPy
- NLP (custom text pipeline)
